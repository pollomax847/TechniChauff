# TechniChauff

Application mobile de terrain pour les techniciens chauffage : relevés techniques, calculs, diagnostics et rapports PDF.

[![Version](https://img.shields.io/badge/version-v0.2.0%2B17-blue)](https://github.com/pollomax847/TechniChauff/releases/tag/v0.2.0-b17)

## Dernière version : 0.2.0+17

Publiée le 23 août 2026. Cette version est disponible en deux variantes :

- **Complete** : tous les modules de calcul, diagnostic et rapport.
- **Technicien** : version allégée pour l'intervention terrain.

## Fonctions principales

- Relevés techniques chaudière, PAC, climatisation, radiateurs et VMC.
- Calculs de puissance, ECS, hydraulique et dimensionnement.
- Rapports de visite, réception, constat, relevé et rapports libres.
- Export PDF, Excel et partage des documents.
- Sauvegarde locale des brouillons, photos et signatures.
- Collecte locale des logs pour faciliter le diagnostic.
